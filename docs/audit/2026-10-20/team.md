# Область: Команда, рейтинги, Академия

## Итог
- **В порядке.** Трейдер чужого не видит: все `?trader=` / `?user=` / `?student=` с чужим именем молча возвращают его собственные данные, а staff-маршруты отвечают 403. Квесты и очки дисциплины начисляются за план, разбор, соблюдённый контракт, тренажёр и уроки, никогда за прибыль. UI переведён полностью: в RU/EN/UZ одинаковые ключи, в TSX нет кириллицы, в UZ-ответах API русских системных текстов нет. Все ответы приходят быстрее 0,2 с, 157 тестов области зелёные.
- **Сильнее всего болит.** Лестница Стажёр→Джун→Трейдер→Сеньор хранится в трёх местах, и «нет ступени» каждый экран понимает по-своему. Реальный трейдер chert (270 сделок) не назначен никуда: «Путь трейдера» у него в тупике, а меню и замки плейбука считают его Стажёром. Академия только на русском и никак этого не помечает, а уроки и тесты входят в критерии перевода. Рейтинг деска считается на R, но R есть у 1 сделки из 1 180, поэтому половина весов достаётся всем бесплатно.
- **Права.** Любой куратор может переписать критерии перевода всего деска и назначить ступень кому угодно. Правило «куратор видит только своих» в Академии включить нельзя: там проверяется роль, а не матрица прав.
- **Первыми я бы сделал три вещи:**
  1. Один источник ступени для всех экранов. Стажёр по умолчанию для трейдера без ступени. Перевод по «Пути» обновляет и тир риска.
  2. Вход в Академию для незачисленного трейдера: сразу курс и «следующий урок». Плюс плашка «урок на русском» для UZ/EN.
  3. Закрыть на админа настройку лестницы и демо-сиды. Перевести Академию на матрицу прав.

## Сквозные находки по области
- **Лестница — не один источник (P1).** Ступень читается из трёх таблиц по цепочке `academy_trader_stage → academy_enrollments.stage → trader_risk_limits.tier`. Цепочка заново реализована как минимум в 6 местах: `academyPathStore`, `discussionAudience.pickStage`, `playbookToday/tier`, `curator.ts`, `author-notes.ts`, `quests/load`. Ещё 6 мест читают только `tier`: `leaderboard.ts:268`, `ratings.ts:282`, `users.ts:382`, `usage/stats.ts`, `admin-console.ts`, `academyPeople.ts`.
  - Перевод по «Пути» (`setStage`, `academy-path.ts:500`) пишет только `academy_trader_stage`. Тир риска (`trader_risk_limits.tier`) и лимиты остаются от прошлой ступени, и обратно тоже ничего не синхронизируется.
  - «Нет ступени» у chert понимают по-разному. Меню и замки плейбука считают его Стажёром (`nav-model.ts`). «Путь» пишет «не назначена» и критериев не показывает. Обсуждения не включают его в аудиторию «Стажёрам». Квесты относят к ученикам только по правилу «не торговал 30 дней».
  - Ключи `trainee/junior/trader/senior` повторены примерно в 20 файлах, плюс «lead», который есть только в масштабировании. Названия в UI тоже смешаны: «уровень», «ступень», «тир», «Уровень риска».
- **Права (P1).** Куратор по умолчанию видит весь деск: `DEFAULT_SCOPE = desk`, `role_permissions` пуст. Проверено: `/curator/trader/Закир`, `/quests/trader/Закир`, `/gamification/me?trader=Закир`, `/academy/*?user=Закир` → 200. Кабинет куратора и квесты честно уважают матрицу, а Академия и `staffOnly` в «Пути» — нет. Если владелец решит «только свои» (вопрос №11), Академия этот выбор проигнорирует.
- **R пуст по всему деску.** У 1 179 из 1 180 сделок нет стопа и риска. Метрики в R (рубрика куратора `maxLossR/avgR`, матожидание и PF в лидерборде, просадка в R) везде null или откатываются к значениям по умолчанию. Это корень ошибки в рейтинге.
- **Приватность непоследовательна.** Топ дня скрывает имена. При этом `/training/trades/:id` показывает трейдеру имя «Закир» у чужой сделки, `/discussions/audience` — всех со ступенями, `ticker-context` — $ деска, а урок 2 называет трейдера с его P&L.
- **Люди хранятся по имени.** `users.assigned_curator`, все таблицы `academy_*`, `discussion_votes.trader`, `curator_notes.trader` — везде TEXT без внешнего ключа. Переименование или удаление рвёт связи (см. сироты в Академии).
- **i18n.** UI в порядке: ключи RU/EN/UZ совпадают, в `academyPath` EN/UZ просто меньше форм множественного числа. API отдаёт RU по умолчанию, язык берёт из `X-Lang` или `users.locale` (не из Accept-Language). В UZ-ответах кириллица только в пользовательских данных: имена, названия когорт, награды, сетапы плейбука. Контент Академии — только RU.
- **Телефон (по коду).** Таблицы обёрнуты в горизонтальный скролл. Много целей для пальца 28–32 px (h-7/h-8, size sm): обсуждения 12, профиль куратора 20, «Группа» 22.
- **Производительность.** Сейчас всё до 0,2 с (2 пользователя). Риски роста: воронка «Пути» (N×7 запросов), «Наставник» (запросы в цикле), лидерборд за всё время (тянет все сделки деска в память), `/ratings` (всё до 2 000 строк), обсуждения (200 тем со всеми комментариями).
- **Мёртвый код и маршруты.** `/discussions/unanswered` (не вызывается), тип `question` (сервер его знает, в UI его нет).
